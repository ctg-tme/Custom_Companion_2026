# Custom Companion User Guide

> **Status:** Content outline. The final procedures and screenshots still need to be written and validated on a supported Companion Device.

This guide is for In-Room Users who move or operate a Companion Device. It will focus on the touch interface and expected room experience, without requiring RoomOS administration knowledge.

## Planned contents

### 1. Meet the Companion Device

- What the Companion Device is
- What a Parent Room Device is
- The difference between Standalone and Paired
- What Custom Companion changes—and what it leaves alone

### 2. Open Companion Device Select

- Find the Custom Companion action button
- Open the controls with PIN Mode disabled
- Enter the current PIN when PIN Mode is enabled
- Understand the protected-session timeout

### 3. Choose how to use the Companion Device

- Select a registered Parent Room Device
- Recognize connection progress and success
- Return to Standalone
- Understand what happens when a Parent Room Device is unavailable

### 4. Use calls while Paired

- Start calls from the Parent Room Device
- Join a supported Webex call as a Guest
- Enter a Meeting Password when prompted
- Understand unsupported call-platform guidance
- End a call from the Companion Device when the control is available
- Continue a call during Call Preservation

### 5. Understand Paired behavior

- Microphone, volume, and incoming-call behavior
- Available and hidden RoomOS controls
- Parent Room Device standby synchronization
- Five-minute and 30-minute standby bypass
- Restoration of Standalone preferences

### 6. Manage Parent Room Devices

- Register a Parent Room Device from the in-room interface
- Confirm the expected Parent Room Device identity
- Replace an existing Parent Room Registration
- Deregister a Parent Room Device with a three-second hold
- Understand Pending Deregistration

### 7. Manage PIN Mode

- Turn PIN Mode on or off
- Change the current PIN
- Re-enter the PIN for registration and deregistration
- Know when to contact a Device Administrator

### 8. Read status and error messages

- Selection and connection messages
- Call and Meeting Password guidance
- Standby messages
- Unhealthy State guidance

### 9. Everyday scenarios

- Move the Companion Device into a registered room
- Use it temporarily as a Standalone device
- Recover from a Parent Room Device connection interruption
- Leave a room ready for the next user

### 10. Get help

- Information to give a Device Administrator
- Actions an In-Room User should not attempt
- Where to find the installed version and support details

For implementation-level behavior, see the [Technical Reference](technical-reference.md).
