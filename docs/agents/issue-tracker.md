# Work intake

This repository does not use a persistent issue tracker. The user reports the current bugs, feature requests, and maintenance work directly in the active chat.

## Rules

- Treat the user's explicit request as the current work package.
- Do not create GitHub Issues, local issue files, PRDs, or triage records unless the user explicitly asks for them.
- Git history, source, `README.md`, `CONTEXT.md`, and ADRs hold durable project state; do not create a rolling chat-handoff artifact.
- If part of a work package cannot be completed, report the remaining item and the exact evidence or decision needed.
